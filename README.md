## ✨ What can CaliBot do?

CaliBot is designed to make managing your Discord server fun and visually stunning. It comes with its own website where you can control everything with a few clicks!

- 📈 **Track Your Server**: See how active your server is with beautiful daily message charts.
- 🏆 **Level Up System**: Users earn XP by chatting! Check who is the most active member on the beautiful web leaderboard.
- 🎨 **Gorgeous Dashboard**: A dark, modern, and sleek website to manage your bot settings easily.
- ⚙️ **Instant Settings**: Turn features on or off directly from the website without typing complicated commands.
- 🔨 **Advanced Moderation System**: Automatically ban, kick, or mute rule-breakers. Includes a full web log of all infractions!
- 🎟️ **Ticket System**: Let your community easily open support tickets managed via the dashboard.
- 🤖 **AI Chatbot**: Talk to CaliBot naturally using Artificial Intelligence.
- 🛡️ **Secure Login**: Log in safely using your own Discord account.
